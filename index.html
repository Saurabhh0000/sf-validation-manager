    📋 Setup Instructions

    Step 1: Create a Salesforce Developer Org

    Go to developer.salesforce.com/signup and create a free developer org.

    Step 2: Create Validation Rules on Account

    Go to Setup → Object Manager → Account → Validation Rules and create 4-5 validation rules. Example rules:

    • Phone Required – Phone cannot be empty
    • Website Format – Website must start with http
    • Industry Required – Industry must be selected
    • Rating Required – Rating cannot be blank
    • Annual Revenue Positive – Annual Revenue must be > 0

    Step 3: Create a Connected App

    1. Go to Setup → App Manager → New Connected App
    2. Fill in the name: ValidationRuleManager
    3. Check "Enable OAuth Settings"
    4. Set Callback URL to: https://localhost:8443/index.html
    5. Add OAuth Scopes: Full access (full) and Manage user data via APIs (api)
    6. Uncheck "Require Proof Key for Code Exchange (PKCE)"
    7. Save and wait 2-10 minutes for it to activate
    8. Copy the Consumer Key — you'll paste it in the app

    Step 4: Enable CORS

    1. Go to Setup → CORS
    2. Click New
    3. Add: https://localhost:8443
    4. Save

    Step 5: Run this App

    Open this folder in VS Code and use the Live Server extension (port 5500) to run it. Then click the Login button!
